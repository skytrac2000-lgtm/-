# Трактор-турбо — проект для сборки APK с телефона

Этот проект оборачивает исходную HTML-игру в Android-приложение с Capacitor.

## Сборка без компьютера

1. Скачай ZIP и распакуй его на телефоне.
2. Создай репозиторий на GitHub через браузер телефона.
3. Загрузи в репозиторий все файлы и папки из ZIP, включая скрытую папку `.github`.
4. Открой вкладку **Actions** в репозитории.
5. Выбери workflow **Build Android APK** и нажми **Run workflow** (или дождись автоматической сборки после загрузки файлов в ветку `main`).
6. Когда задача завершится успешно, открой её страницу, найди **Artifacts** и скачай `tractor-turbo-debug-apk`.
7. Распакуй скачанный архив и установи `app-debug.apk`. Android может попросить разрешить установку приложений из этого источника.

## Важно
- Для загрузки Three.js из unpkg игре нужен интернет.
- Это debug APK для установки и тестирования, не подписанный релиз для публикации в Google Play.
- Если GitHub Actions недоступен или сборка завершится ошибкой, пришли текст ошибки — помогу исправить.
